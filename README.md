# EduVision Vercel Complete

1. Put your existing Supabase Project URL and PUBLIC anon/publishable key into config.js.
2. Never use the service_role key in config.js.
3. Add EDUVISION_ADMIN_ID and EDUVISION_ADMIN_PASSWORD in Vercel Environment Variables.
4. Do not add vercel.json. Vercel detects main.py.

Includes the full HTML dashboard, roles, students, teachers, manual attendance, reports, school approvals and browser camera. Automatic OpenCV face recognition and YOLO occupancy require a separate AI backend conversion.
